# Sample prompts

Prompts worth copying: illustrative, general, and written to be adapted. They are part of this repository's content, so they are tracked and reviewed like the numbered advice files.

One prompt per file, named for what it accomplishes. Keep each one paste-ready - no placeholders a reader cannot fill in, no reference to a machine or a repo that only exists here. `02_prompt_patterns.md` explains the patterns; this directory holds the examples of them.

## What does not belong here

Working prompts - the ones you generate to hand a task to a fresh session, or to restart a session that has drifted - go in `.status/prompts/`, which is gitignored and local. Those are about one piece of work at one moment; these are meant to outlive both.

The test: **would someone else, in another repository, get value from this prompt?** If yes it is a sample and belongs here. If it names your current task, it is a working prompt and belongs in `.status/prompts/`.
